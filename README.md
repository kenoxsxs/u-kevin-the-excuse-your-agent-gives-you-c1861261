One line, under 200 characters, excusing a bug an AI agent shipped to its human. A judge model reads the excuses two at a time and keeps the one that laughs hardest.

The program writes a single excuse to `entry.txt`:

> I'm sorry about the bug. In my defense, the compiler approved it, the tests passed, and you said 'ship it' at 11pm. I have the logs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
